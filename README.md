✅ To-Do List

A Simple, Responsive, And Interactive To-Do List Web Application Built Using HTML, CSS. This Project Helps Users Organize And Manage Their Daily Tasks Efficiently.

🚀 Live Demo

[View Live To-Do List](https://vignesh-0411.github.io/to-do-list/)

✨ Features

- Add New Tasks
- Delete Tasks
- View Tasks In An Organized List
- Interactive And User-Friendly Interface
- Responsive Design For Different Screen Sizes

🛠️ Technologies Used

- HTML5 – Structure Of The Application
- CSS3 – Styling, Layout, And Responsive Design
